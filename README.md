# Grade Calculator

**Name:** JOHN PAUL P. VILLAREAL  
**Section:** IT3R10

## Description

A small Python command-line program that calculates the arithmetic average of
grades. Enter one or more grades from 0 to 100, separated by commas. The
program checks the input and displays the number of grades, the lowest and
highest grades, and the average to two decimal places.

## Requirements

- Python 3.9 or later

## How to run

Open a terminal in this folder and run the command for your operating system.

```powershell
py -3 grade_calculator.py
```

On macOS or Linux, use `python3 grade_calculator.py`.

When prompted, enter grades such as `85, 90, 78.5`. Run the tests on Windows
with `py -3 -m unittest -v`, or on macOS/Linux with `python3 -m unittest -v`.
