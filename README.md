# Grade Calculator

**Name:** JOHN PAUL P. VILLAREAL  
**Section:** IT3R10

## Description

A small Python command-line program that calculates the arithmetic average of
grades. Enter one or more grades from 0 to 100, separated by commas. The
program checks the input and displays the average to two decimal places.

## Requirements

- Python 3.9 or later

## How to run

Open a terminal in this folder and run:

```powershell
python grade_calculator.py
```

When prompted, enter grades such as `85, 90, 78.5`.
